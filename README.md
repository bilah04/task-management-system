# Task Management System

A simple Task Management System built using Laravel 12.

# Features
- User Authentication (Register/Login/Logout)
- Create Task
- Edit Task
- Delete Task
- Search Tasks
- Filter Tasks by Status
- Success Alert Messages

# Technologies Used
- Laravel 12
- PHP 8.2
- SQLite
- Tailwind CSS
- Laravel Breeze
